## Definitions

Units, as in `CONTRACT.md` (section Stats):

- **project**: one transcript directory under `~/.claude/projects` (a working directory); `project-01` has the most sessions. Ties go to the project with more edits.
- **sessions**: transcript files read for the project (one row per `.jsonl`, subagent transcripts included).
- **files**: distinct files edited in the project's transcripts. Files under `/tmp`, the OS temp directory and `~/.claude` are not counted as edits.
- **file edits**: (transcript, file) pairs with at least one edit; the denominator of `unrun`, `strict` and `no pass`.
- **edits**: edit events (Edit, Write, MultiEdit, NotebookEdit, and shell commands that changed a file).
- **runs**: shell commands classified as test, lint, type-check, build or script invocations; the outcome is parsed from their output.
- **commits**: successful `git commit` calls in the transcripts.
- **unrun**: file edits whose last edit has no run after it in the same transcript.
- **strict**: file edits whose last edit has no targeted run after it (a run is targeted when the command names the file, its stem or its parent directory, or is a whole-project run with no path arguments).
- **no pass**: file edits whose last edit has no passing run after it.
- **commit after edit**: of the commits preceded by an edit in the same transcript, those that include an edit made after the last run (the footer also gives the count after the last passing run).

Every ratio prints as `n/d (p%)`. Nothing here is a judgement of quality, only of what ran after what. The per-hunk definitions used by the PR report (hunk, attribution, run, status, targeted, cost) are in the README.
