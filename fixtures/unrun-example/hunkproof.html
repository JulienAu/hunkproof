Definitions

hunk
A hunk is one contiguous block of added or removed lines in the diff between the base and head commits (git diff -U0). Its id is the file and the first new line number.
attribution
MATCHED (line-matched): most of the added lines appear in an edit the agent made to this file during a session; only these hunks count as attributed in the headline. FILE_LEVEL: the agent edited this file in a session, but the added lines could not be found in any edit, so the run timing is relative to the file's last edit, not to the lines. UNATTRIBUTED: no session edit of this file was found, or the only edits of the file predate the branch base commit. Working-tree changes a shell command cannot have written (a merge, files changed by another agent while the command ran) are not counted as edits.
run
A run is a shell command that executes code: a test runner, a linter, a type checker, a build, or a direct script invocation. Commands that only write files are not runs, nor are hunkproof's own invocations. Outcome is pass, fail, or unparsed when the exit status and output could not be read (including commands moved to the background).
status
Decided by the last run after the hunk's last edit whose outcome was parsed, targeted runs first; a run made in another checkout than the edit (a git worktree) never decides. RUN_PASS: that run passed. RUN_FAIL: it failed ("ran, failed"). RUN_UNPARSED: runs happened after the last edit but none had a parsable outcome ("ran, outcome not parsed"). UNRUN: no run at all after the last edit. UNATTRIBUTED: the hunk could not be tied to a session edit, so nothing is known about runs.
targeted
A run is targeted when the command names the file, its stem or its parent directory, or when it is a whole-project run with no path arguments. The strict count only accepts targeted runs after the last edit.
cost
Token counts come from the session transcripts, deduplicated per API call. The dollar figure is what these tokens would cost at Anthropic API list prices; not a bill (subscription plans have no per-token charge); it comes from a dated public price table and is not what was billed. Models without a price entry are listed and left out of the total. Hunkproof itself makes no LLM call (0 tokens).
